# Brainfuck-plus-plus
An interpreter for the Brainfuck++ language

##Core Principles
Brainfuck++ is meant to be a superset of original brainfuck ie. All valid brainfuck code should be valid brainfuck++ code. It is also designed to not abstract to much from the core of moving a pointer around an array of bites and modifying individual values. There are abstractions, but it's C level abstractions not Python level abstractions, to put in simpler terms.
